# FlexClub

Учебный сайт тренажёрного клуба на Laravel 12, Blade и MySQL/MariaDB. В приложении есть публичный каталог, кабинеты клиента и тренера, а также раздел администратора.

## Запуск на Windows с XAMPP

Понадобятся PHP 8.2 или новее, Composer, расширение `pdo_mysql` и MySQL 8.0.16+ либо MariaDB 10.4+. Команды ниже выполняются в PowerShell из корня проекта. Если XAMPP установлен в другой каталог, укажите свой путь к PHP.

1. Запустите MySQL в XAMPP и создайте пустую базу `flexclub` через phpMyAdmin. Для SQL-консоли команда выглядит так:

   ```sql
   CREATE DATABASE flexclub CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. Установите зависимости и скопируйте конфигурацию:

   ```powershell
   $env:Path = "C:\xampp\php;$env:Path"
   composer install
   Copy-Item .env.example .env
   ```

3. Укажите в `.env` адрес, порт, имя базы, пользователя и пароль MySQL. В примере настроено локальное подключение XAMPP с пользователем `root` и пустым паролем. Затем выполните:

   ```powershell
   php artisan key:generate
   php artisan migrate
   php artisan serve
   ```

4. Откройте [FlexClub](http://127.0.0.1:8000). CSS, JavaScript и изображения находятся в `public`, поэтому для запуска приложения сборка npm не требуется.

Миграция сама применяет `database/flexclub.sql`. Этот SQL также можно отдельно импортировать в пустую базу для просмотра схемы в phpMyAdmin. Для базы приложения используйте миграции. Стандартные филиалы и тарифы добавляются вместе со схемой. Локальные сеансы и кэш хранятся в файлах.

Если в каталоге тренеров ещё нет записей, миграция добавляет шесть карточек из исходной вёрстки. Если схема была импортирована вручную, эти карточки можно загрузить командой `php artisan db:seed --class=TemplateTrainerSeeder`. Для проверки переписки используйте учётную запись тренера из демонстрационного набора.

## Набор для демонстрации

В новой базе с `APP_ENV=local` можно загрузить 31 тренировку и 30 записей:

```powershell
php artisan db:seed --class=DemoSeeder
```

| Роль | Email |
| --- | --- |
| Администратор | `admin@flexclub.test` |
| Тренер | `trainer@flexclub.test` |
| Клиент | `client@flexclub.test` |

У всех трёх демонстрационных учётных записей пароль `FlexclubDemo2026`. Даты в наборе рассчитываются относительно дня загрузки. Для проверки новой заявки зарегистрируйте клиента через сайт, выберите зал и тариф, подайте заявку и одобрите её из кабинета администратора.

Учётные записи сотрудников можно создавать через консоль:

```powershell
php artisan flexclub:user admin
php artisan flexclub:user trainer
```

После создания учётной записи тренера администратор заполняет карточку и указывает филиалы в разделе «Залы, тренеры и тарифы». Для фотографий укажите относительный путь в `public`, например `images/coaches/coach-1.png`.

## Проверка

Создайте отдельную пустую базу `flexclub_test` с теми же параметрами подключения и выполните:

```powershell
$env:DB_DATABASE = "flexclub_test"
$env:FLEXCLUB_TEST_DATABASE = "flexclub_test"
php artisan migrate
php artisan test
Remove-Item Env:FLEXCLUB_TEST_DATABASE, Env:DB_DATABASE
```

Интеграционные тесты проверяют регистрацию и права, расчёт и одобрение заявки, лимиты записи и вместимости, отмену, повторную запись, отметку посещения, справочники и доступ к диалогам.
